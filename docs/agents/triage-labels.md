# Triage Labels（Triage 标签）

各 skill 以五个规范 triage 角色说话。本文件把这些角色映射到本仓库 issue tracker 实际使用的标签字符串。

| mattpocock/skills 里的标签 | 我们 tracker 里的标签 | 含义 |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | 维护者需要评估这个 issue |
| `needs-info`               | `needs-info`         | 等待报告者提供更多信息 |
| `ready-for-agent`          | `ready-for-agent`    | 完全指定，准备给 AFK agent |
| `ready-for-human`          | `ready-for-human`    | 需要人工实现 |
| `wontfix`                  | `wontfix`            | 不会处理 |

当 skill 提到一个角色（如"打上 AFK-ready triage 标签"），用本表里对应的标签字符串。

编辑右列以匹配你实际使用的词汇。
